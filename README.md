# Asendra Chauhan — Production Portfolio

A production-ready static portfolio focused on **full-stack product engineering, connected SaaS systems and practical GenAI engineering**.

## What is included

- Editorial, developer-first visual system
- Global light/dark theme with persistence
- Six-language UI: English, Hindi, Spanish, French, German, Japanese
- Responsive navigation and mobile menu
- Interactive product-engineering system map
- KiteSuite flagship contribution case study
- KiteSuite screenshot gallery + accessible lightbox
- Architecture: UI → API → data → integrations → AI → production
- Skills matrix covering frontend, backend, data, GenAI, testing, delivery and tooling
- Resume-backed proof metrics
- Experience timeline
- Education + public links
- Contact flow using a mailto draft
- SEO metadata, Open Graph, Twitter metadata, JSON-LD
- Sitemap, robots.txt, favicon, web manifest and 404 page
- Netlify security headers
- Reduced-motion accessibility support

## Deployment

### GitHub Pages
Upload the contents of this folder to the repository used by the GitHub Pages site. The existing canonical path is:

`https://asendrachauhan.github.io/Asendra-portfolio/`

### Netlify
Deploy this folder directly. `netlify.toml` is already included.
