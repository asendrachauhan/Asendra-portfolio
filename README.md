# Asendra Chauhan — Production Portfolio

Static, dependency-light portfolio implementation based on the supplied portfolio brief, older resume, and curated KiteSuite screenshots.

## Run

Serve the directory with any static server. Example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Included
- Responsive editorial engineering design
- Light/dark theme with persistence
- English, Hindi, Spanish, French, German, Japanese translations
- Meaningful product/system visualization instead of decorative 3D
- KiteSuite case study with curated evidence and expandable gallery
- Systems/architecture section
- Practical GenAI section
- Historical experience and resume-derived metrics clearly scoped
- Contact form with validation + mailto fallback
- Accessibility and reduced-motion considerations
- SEO metadata + Person structured data
- No framework dependency; easy to deploy to Netlify, Vercel, GitHub Pages or any static host
